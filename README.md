# VK Дашборд — сайт на GitHub Pages

Сайт со статистикой всех кабинетов VK Рекламы, доступный из любой точки мира.
Работает без вашего компьютера и без моего сервера: данные собирает сам GitHub.

## Как это устроено

```
GitHub Actions (каждые 30 минут)                    вы открываете сайт
        │                                              в любом браузере
        ▼                                                    ▲
скрипт scripts/fetch_and_export.mjs                            │
запрашивает VK Рекламу по токенам                      GitHub Pages отдаёт
из секретов репозитория                          index.html + data.json
        │                                                    ▲
        ▼                                                    │
пишет data.json и коммитит его в репозиторий ────────► сайт обновляется сам
```

Никаких серверов платить не надо. Токены лежат в Secrets репозитория —
их не видно никому, даже в публичном репозитории.

## УСТАНОВКА — 5 шагов (около 10 минут)

### Шаг 1. Создайте репозиторий

1. Зайдите на github.com (аккаунт можно создать бесплатно).
2. Нажмите **New repository** (зелёная кнопка) или откройте https://github.com/new
3. Имя: например `vk-dashboard`
4. Видимость — важный выбор:
   - **Public (публичный)** — бесплатно, GitHub Pages работает сразу.
     Минус: статистика ваших клиентов (остатки, расходы) видна любому,
     кто знает ссылку. Ссылку знаете только вы, но она не защищена паролем.
   - **Private (приватный)** — репозиторий и статистика скрыты ото всех,
     но GitHub Pages в приватном репозитории работает только на платном
     тарифе Pro (~4 $/мес).
   - Рекомендация: если у вас нет Pro — выбирайте Public и просто
     никому не давайте ссылку. Метрики в таблице без фамилий и деталей.
5. Нажмите **Create repository**.

### Шаг 2. Загрузите файлы

В окне «Quick setup» нажмите **uploading an existing file**
(или в существующем репозитории: **Add file → Upload files**).

1. Распакуйте архив, присланный ассистентом.
2. Откройте папку, **выделите ВСЕ файлы внутри** (Ctrl+A) и перетащите
   их в окно загрузки GitHub. Важно: перетаскивайте содержимое папки,
   а не саму папку — тогда index.html окажется в корне репозитория.
   Файл **«СЕКРЕТ-не-загружать-в-репозиторий.txt» НЕ загружайте** —
   он нужен только для шага 3.
3. Дождитесь, пока все файлы загрузятся (появится список:
   index.html, style.css, app.js, data.json, cabinets.json, README.md,
   папка scripts), и нажмите **Commit changes**.

Если скрытая папка `.github` не перетащилась (в списке файлов её нет):

- **Add file → Create new file**
- В поле имени введите: `.github/workflows/update-stats.yml`
- Откройте файл `workflow-копия-для-вставки-через-веб.txt`,
  скопируйте всё содержимое и вставьте в поле кода
- **Commit changes**

### Шаг 3. Добавьте токены в секреты

1. В репозитории: **Settings → Secrets and variables → Actions →
   New repository secret**
2. Name: `VK_TOKENS` (точно так, латиницей, без пробелов)
3. Secret: откройте файл **«СЕКРЕТ-не-загружать-в-репозиторий.txt»**,
   скопируйте строчку с `{...}` ЦЕЛИКОМ и вставьте
4. **Add secret**

### Шаг 4. Включите GitHub Pages

1. **Settings → Pages**
2. Build and deployment → Source: **Deploy from a branch**
3. Branch: `main`, папка `/ (root)` → **Save**
4. Подождите 2–3 минуты, обновите страницу — сверху появится адрес
   сайта вида: `https://ВАШ_ЛОГИН.github.io/vk-dashboard/`

### Шаг 5. Запустите первое обновление вручную

1. Вкладка **Actions** в репозитории (сверху)
2. Слева выберите **«Обновление статистики VK»**
3. Справа **Run workflow → Run workflow** (зелёная кнопка)
4. Дождитесь зелёной галочки (1–3 минуты)
5. Откройте сайт — таблица с живыми данными готова!

## Частые вопросы

**Как часто обновляются данные?**
Каждые 30 минут по расписанию (запуск можно поменять в файле
`.github/workflows/update-stats.yml` — строка `cron`). Открытая страница
сама подтягивает свежие данные каждые 5 минут. Кнопка «Обновить» на
странице — мгновенно. Github может запускать задачу с задержкой в пару минут — это нормально.

**Что значит «лимит токенов» / «нет ключа API» в таблице?**
Как в рабочей панели: у кабинета нет рабочего токена VK
(Воздух ждёт освобождения слота, Адамович и Шарок — жду ключи от вас).
Когда появятся новые токены — см. следующий пункт.

**Как обновить токены?**
Когда ассистент получит новый токен для кабинета, он пришлёт обновлённый
файл `СЕКРЕТ-...txt`. Зайдите в **Settings → Secrets and variables →
Actions → VK_TOKENS → Update secret**, вставьте новое значение и
запустите Run workflow. Также добавьте кабинет в `cabinets.json`
(просто скопируйте готовый файл, который пришлёт ассистент).

**Воздух (Куляшова) — когда появится?**
VK сейчас не даёт токен (заняты слоты старыми). Мой сервер продолжает
пробовать автоматически. Как только получится — пришлю обновлённый
файл секретов, вы обновите VK_TOKENS, и кабинет появится на сайте.

**Данные пропали / страница пустая**
Откройте вкладку **Actions** — если последний запуск красный, нажмите
на него и посмотрите лог. Чаще всего это временная ошибка сети до VK —
следующий запуск через 30 минут всё исправит. Можно нажать Run workflow.

**GitHub присылает письмо про отключение расписания**
GitHub отключает cron, если в репозитории 60 дней нет активности.
Просто зайдите в Actions и нажмите Run workflow — таймер обнулится.

**Как обновить сам сайт (новая версия от ассистента)?**
Загрузите новые файлы через **Add file → Upload files** поверх старых
(GitHub предложит Commit changes). Сайт перестроится сам.

## Файлы репозитория

| Файл | Назначение |
|---|---|
| `index.html` | страница сайта (та же широкая таблица, что в рабочей панели) |
| `style.css` | оформление |
| `app.js` | логика: таблица, сводка, карточка клиента по клику на строку |
| `data.json` | данные VK — обновляется автоматически каждые 30 минут |
| `cabinets.json` | список кабинетов (названия и ID, без секретов) |
| `scripts/fetch_and_export.mjs` | скрипт сбора данных (запускает GitHub) |
| `.github/workflows/update-stats.yml` | расписание автосбора данных |
